# CocoCafe Project

## Overview
CocoCafe is a delightful coffee shop website designed to provide users with an engaging experience. The website features a modern design with a focus on usability and aesthetics, showcasing a variety of coffee and cookie offerings.

## Project Structure
The project is organized as follows:

```
CocoCafe
├── assets
│   └── images          # Contains all image assets used in the project
├── css
│   └── styles.css      # Styles for the website
├── js
│   └── script.js       # JavaScript for interactivity
├── index.html          # Main HTML file for the project
└── README.md           # Documentation for the project
```

## Features
- **Navigation Bar**: Includes a unique logo, menu button, rewards and gift card options, a "Find a Cafe" feature, and "Sign In" and "Join Now" buttons.
- **Hero Section**: Features an "eGift" button and a visually appealing card image, set against a beautiful coffee beans background.
- **Special Coffee Section**: Showcases special coffee offerings with an "Order Now" button.
- **Cookie Section**: Displays delicious cookie images.
- **Footer**: Designed similarly to the Starbucks website for a familiar user experience.

## Color Palette
- White
- Amazon Green (RGB 59, 122, 87)
- Deep Jungle Green (RGB 28, 48, 41)

## Setup Instructions
1. Clone the repository or download the project files.
2. Open the `index.html` file in a web browser to view the website.
3. Ensure that all assets are correctly linked in the HTML file.
